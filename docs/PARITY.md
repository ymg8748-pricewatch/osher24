# מיפוי יכולות: PriceWatch ← אושר24 (סניף מול סניפים)

"הסניף שלי" = הסניף שנבחר (ברירת מחדל: בת הדר). "המתחרים" = 23 סניפי אושר עד האחרים.

## הועבר ועובד (בלי שינוי במסד)
| ב-PriceWatch | באושר24 |
|---|---|
| חיפוש לפי שם / ברקוד, סריקת מצלמה, הקלדת ברקוד | חיפוש, הצעות תוך כדי הקלדה, סריקה (גם ברצף), תמונה, סריקות אחרונות |
| דף מוצר: מחיר בכל סניף מול שלי | רשימת 24 סניפים, שלי תמיד ראשון, פער מול שלי, מרחק |
| "כולל מבצעים" / "מחיר מדף בלבד" | מתג בראש הדף, משפיע על כל המסכים והייצוא |
| תצוגות המוצר: טבלה / חריגים קודם / מפת חום | שלוש תצוגות (קבוצות מחיר, המחיר הנפוץ כייחוס, אריחים צבועים) |
| סל מוצרים, שינוי כמות | סל, כמויות, סניף מומלץ לסל |
| ייצוא סל: Excel, PDF, תמונה לוואטסאפ | Excel (עם נוסחאות), PDF, תמונה, טקסט |
| סינון פער ("זולים/יקרים ממני ב-₪X") | סינון בדף המוצר + דוח "איפה אני יקר" |
| מנהל / צופה | מנהל רשת (admin), מנהל סניף (branch), צופה (viewer, בלי סל וייצוא) |
| התראת נתונים ישנים | באנר + `/api/health` להתראה חיצונית |

## עדיין לא הועבר: דורש החלטה או נתון שאין לאתר החדש
| יכולת | למה |
|---|---|
| מחלקות (דף הבית, גלגל, דף מחלקה), מכ"ם, ביצים, סל מחלקה | אין שדה מחלקה בנתוני הסניפים. הסיווג ב-PriceWatch הוא קוד לפי שם מוצר (`classify.js`) שמורץ על כל הקטלוג. אפשרות: פונקציה `br24_list` שמחזירה את הקטלוג בעמודים, וסיווג באתר עם מטמון. דורש אישור כי זו סריקה של כל הטבלה |
| שינויים השבוע, מגמת פער, סל מפתח לאורך זמן | דורשים היסטוריית מחירים לסניפים. הטבלה `br24` שומרת רק את הריצה האחרונה |
| לפי יצרן | אין שדה יצרן בנתוני הסניפים |
| אימות דו-שלבי (2FA) למנהל | לא נבנה עדיין. אפשר עם `ADMIN_TOTP_SECRET` בלי מסד |
| ייצוא PDF לרשימת "איפה אני יקר" | יש Excel וטקסט לוואטסאפ. PDF קיים למוצר ולסל |

## דולג: לא הגיוני בהשוואה בין סניפים של אותה רשת
- התאמת מוצרים ידנית בין רשתות (`match`, `simsearch`): אותו ברקוד בכל הסניפים.
- שמות, צבעים ומקורות של רמי לוי / יוחננוף, "שני המתחרים" (b24 כבר משווה לכל הסניפים).
- הזנת נתונים (`ingest`, `finalize`, GitHub workflows, `fetch_prices.py`): נשארים ב-PriceWatch, האתר החדש לא כותב למסד.
- ניהול משתמשים במסד (`/users`): הסיסמאות באתר החדש הן משתני סביבה (`BRANCH_PASSWORDS`, `VIEWER_PASSWORDS`, `ADMIN_PASSWORD`).
- סיווג מחדש של מחלקות (`reclass`, `deptapply`, `deptdump`) ו-`mb_` (גרסת תצוגה מקדימה).
- הסל המאוחד (`UB`): ברשימה ב-PriceWatch הוא ריק (מתמלא מקובץ חיצוני).
- מחיר ליחידת מידה: אין כמות ויחידה בנתוני הסניפים.
